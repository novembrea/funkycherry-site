Prismfall

A neon light-beam breaker for iPhone.

Support

Questions, bugs or ideas? Write to support@funkycherry.games. Please include your iPhone model and iOS version if something went wrong.

How to play

  • Pull back anywhere on the screen to aim, and let go to fire. Your beams bounce off the walls and blocks.
  • Each block shows how many hits it can take. After every shot the blocks move down a row.
  • Break the gold upgrade blocks to pick new beams and upgrades.
  • The run ends when a block reaches the line at the bottom. Once per run you can revive.

Settings

Pause during a run (top left) or tap Settings on the main menu to change the aim mode and to turn sound and haptics on or off.
